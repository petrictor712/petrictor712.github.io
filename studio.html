发布更改

    把文章或头像加入待发布后，即可生成发布内容。

    1. 打开 GitHub 编辑页并聚焦代码编辑区。
    2. 全选原有内容并粘贴复制的内容。
    3. 点击 Commit changes 并提交到 master，部署完成后即可看到更新。
